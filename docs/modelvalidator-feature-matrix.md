# Model-validator plugin feature matrix

Versioned, machine-checkable capability inventory shared across every model-validator plugin in this thesis, cross-mapped against the scenarios in `msc-modelvalidators/benchmark/src/main/resources/manifest.json (17 base scenarios + 16 paired UNSAT mutations)`. Each feature is scored per plugin under its own `support` entry, so a second plugin's capability data slots in next to the first without restructuring anything -- see [modelvalidator-feature-matrix.json](modelvalidator-feature-matrix.json) for the machine-readable form (same data, one row per feature per plugin, with full evidence strings).

This is a *support* inventory, not a *correctness proof*: a status means "this is what the source code and/or a real example run demonstrates" for that specific plugin -- re-verify any row you plan to rely on for a claim in the thesis itself by following its evidence pointer.
